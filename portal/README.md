# Portal

The single front door for the Office ERP — login (including Google Sign-In), new-user registration,
profile updates, and the tile-grid launcher into every pillar (LGDesk today, more later). Own NestJS API +
Next.js web app, npm workspaces monorepo, deployed independently of every other pillar. See
`ERP/SSO_Portal_Architecture_Decisions.md` (repo root) for the full architecture/ownership decisions this
app is built against.
